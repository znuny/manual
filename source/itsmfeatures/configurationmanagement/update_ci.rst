Update a Configuration Item
###########################

To update a **Configuration Item (CI)** in Znuny, follow these steps:

1. Navigate to the Configuration Management Overview, or search for a CI.
2. Click the **CI** to view it.
3. Select Edit.
4. Update the CI details.
5. Save and Review

 - Click **Save** to store the CI in the CMDB.
 - Review the details to ensure everything is correct.

.. note::

    Using the ImportExport module, you can also define templates for updating
    configuration items.
