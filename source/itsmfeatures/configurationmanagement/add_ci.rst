Create a Configuration Item
###########################

To add a **Configuration Item (CI)** in Znuny, follow these steps:

1. Click **Add Configuration Item**.
2. Choose a **CI Class** from the available options:

  - **Computer:** Workstations, laptops, and servers.
  - **Hardware:** Network devices, printers, and other physical equipment.
  - **Location:** Sites, buildings, and rooms.
  - **Network:** Networks and network segments.
  - **Software:** Applications and installed software.

  Additional classes can be added by an administrator; see :ref:`PageNavigation itsmfeatures_configurationmanagement_add_class`.

3. Fill in the CI details:

  - Name: *(Unique name for the CI)*
  - Description: *(Short description of the asset)*
  - Deployment State: *(e.g. Planned, Production, Repair, Maintenance, Pilot, Review, Test/QA, Inactive, Retired, or Expired)*
  - Incident State: *(Operational, Warning, or Incident)*

4. Save and Review

 - Click **Save** to store the CI in the CMDB.
 - Review the details to ensure everything is correct.
 - Link the CI to **incidents, problems, or changes** as needed.

.. note::

    Using the ImportExport module, you can also define templates for importing and exporting
    configuration items.

Edit a Configuration Item
*************************

To edit a **Configuration Item (CI)** in Znuny, follow these steps:

1. Select the CI.
2. Choose **Edit** from the available options.
3. Update the CI details:

  - Name: *(Unique name for the CI)*
  - Description: *(Short description of the asset)*
  - Deployment State: *(e.g. Planned, Production, Repair, Maintenance, Pilot, Review, Test/QA, Inactive, Retired, or Expired)*
  - Incident State: *(Operational, Warning, or Incident)*

4. Save and Review

 - Click **Save** to store the CI in the CMDB.
 - Review the details to ensure everything is correct.
 - Link the CI to **incidents, problems, or changes** as needed.

.. note::

    Using the ImportExport module, you can also define templates for importing and exporting
    configuration items.
