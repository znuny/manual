Changes
*******
- Improved visibility of the current date in the date picker UI element
- Showing the complete value of keys in the system configuration by hovering over it


Fixed Issues
************
- Updated the Google OAuth2 template to always request an access token when needed. Thanks for reporting to `@AeonJJohnson <https://github.com/AeonJJohnson>`_. (`#709 <https://github.com/znuny/Znuny/issues/709>`_)
- Fixed the outgoing email check in the installer.
- Prevent deleting valid web services. They need to be set to not valid before deleting them.

Read about all changes in the `CHANGES.md <https://raw.githubusercontent.com/znuny/Znuny/rel-6_5_17/CHANGES.md>`_. See the commits on `GitHub <https://github.com/znuny/Znuny/commits/rel-6_5_17>`_ for a list of all changes.
